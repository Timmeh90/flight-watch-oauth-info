Privacy Policy

Last updated: 2026-11-11

Flight Watch is a personal, non-commercial desktop application run by an individual on their own computer. This policy explains what the application does with Google user data.

Access requested from Google

The application requests a single Google permission: read-only access to Gmail (https://www.googleapis.com/auth/gmail.readonly). It requests nothing broader, and it refuses to operate with a broader permission.

Why the access is needed

The only purpose is to recognize and process flight price alerts that the user has directed to a specific Gmail label. The application lists messages that carry that label and downloads those messages so it can read the price information in them. It does not read messages without that label.

What the application does not do

  • It does not send, reply to, modify, label, archive or delete any email.
  • It does not open attachments and does not follow links or load images in emails.
  • It does not sell personal data.
  • It does not share data with advertising networks or use it for advertising.
  • It does not use Google user data to train artificial-intelligence or machine-learning models.
  • It does not use cookies, analytics or tracking, and neither does this website.

Where data is processed and stored

  • Email content is processed locally on the user's own computer. The application has no server of its own.
  • For each processed message, the application stores locally: the sender domain and display name, the subject, the sent date, a content hash, a short text excerpt (up to 2,000 characters), and the flight-price information extracted from it (such as route, dates and price). This is kept in a local database file on the user's computer.
  • The OAuth credentials that let the application read Gmail are stored in the operating system's secure credential store (macOS Keychain) on the user's computer. The access token is held only in memory.
  • Flight price lookups use a separate third-party flight price service. Those requests contain only search details such as airports and dates. They do not contain Gmail data.
  • Flight-price information derived from alerts may appear in notifications shown to the user on their own computer or sent to a personal notification channel that the user has configured. Raw email content is not forwarded to anyone.

Compliance with Google API Services User Data Policy

Flight Watch's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements. Gmail data is used only to provide the user-facing flight price alert feature described above, and humans do not read it except as the user does on their own computer.

Revoking access and deleting data

  • Revoke access: the Google account holder can withdraw access at any time at myaccount.google.com/permissions by selecting Flight Watch and choosing to remove access.
  • Remove stored credentials: the application has a command that deletes its Gmail credentials from the Keychain.
  • Delete local data: because all data is held locally, deleting the application's local database file and data folder from the computer removes it.

Contact and changes

Questions can be raised through the issue tracker of the public repository that hosts this website: github.com/Timmeh90/flight-watch-oauth-info/issues. If this policy changes, the updated version and date will be published on this page.

Flight Watch is a personal, non-commercial project. This site is static: no cookies, no analytics, no forms.
